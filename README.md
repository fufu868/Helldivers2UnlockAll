## Unlocked content

This mod grants local access to armors, equipment, and stratagems during active gameplay sessions.

* **Armor:** Unlocks light, medium, and heavy armor sets in the local armory.
* **Equipment:** Unlocks all primary weapons, secondary weapons, and personal gear.
* **Stratagems:** Unlocks all orbital, hangar, bridge, and defensive stratagems on the loadout screen.

## Local scope and limitations

All edits remain local to the client application and do not alter server data.

* **No resource gains:** Does not generate or modify account currencies, including Requisition Slips, Super Credits, Medals, or Samples.
* **Temporary availability:** Unlocked items remain accessible only while the game is running. Closing the game resets all inventory states to the server save.
* **Client-side operation:** Modifies local client memory without sending network commands to update permanent account progression.
